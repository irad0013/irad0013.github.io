Description of Html Tags

<html>
Defines the root of an HTML document. All other elements are contained inside it.
<head>
Contains meta-information about the document, such as title, links, and metadata.
<body>
Contains the visible content of the webpage like text, images, and links.
<h1>
Represents the main heading of a page. It is usually the largest and most important heading.
<p>
Defines a paragraph of text in an HTML document.
